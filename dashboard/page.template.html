Sources
dataset/system_activity.csv, deletion_rules.csv, user_audit_log.csv, evidence_files.csv and the 24 SQL snapshots under dataset/evidence/databases. Organizer-only files are not used.

      
How to read the numbers
Activity results are claims. Rates describe what systems reported, and replica and retention figures come from snapshots. Forecasts are a straight-line fit on nine complete months and carry wide intervals.

      
Graph
The graph is built with NetworkX in dashboard/build_data.py and exported as node-link JSON. This page mirrors the NetworkX calls it needs, so the browser never changes the source data.
